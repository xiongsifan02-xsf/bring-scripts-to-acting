# Bring Scripts to Acting!

Project page for **Bring Scripts to Acting! Content-Variant Control for Emotion-Aligned Acting Generation** (Anonymous ICLR 2027 submission).

## View online

After GitHub Pages is enabled, open:

`https://<your-username>.github.io/bring-scripts-to-acting/`

## View locally

Open `index.html` (or `project page.html`) in a browser. Keep the folder structure so videos/images load correctly.

## Contents

- `index.html` — project homepage
- `demo.mp4` — full video presentation
- `assets/` — clips, figures, and page static files
